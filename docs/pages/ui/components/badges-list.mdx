## Overview

BadgesList wraps badge elements and provides consistent spacing.

## Props

- class: string — additional classes for the container.

## Examples

Inline badges inside a table cell:

<Example>
<BadgesList>
  <Badge text="QTA" color="primary" />
  <Badge text="Event" />
  <Badge text="Tickets" color="warning" />
</BadgesList>
</Example>

## Accessibility

Badges are presentational. Provide textual context for screen readers when badges carry important meaning.
