## Overview

The manufacturing suite ships 17 module pages under `preview/pages/`, plus the
overview dashboard. Every module page follows the same pattern: fetch live data
with typed fetchers from `@shared/lib/fetchers`, and fall back to a matching JSON
file in `shared/data/` when the API is unavailable.

Pages are grouped under **Manufacturing ERP** in the preview menu and all use the
`DefaultLayout` from `@shared/layouts/DefaultLayout.astro`.

## Production

### Products

- Page: `manufacturing-products.astro`
- Shows: microbial product catalog — bio-fertilizers, bio-pesticides, bio-fungicides
- Fetchers: `fetchProducts`, `fetchProductStats`
- Fallback: `shared/data/manufacturing-products.json`

## Shared data layer

All fetchers live in `shared/lib/fetchers.ts` and the TypeScript types live in
`shared/lib/types.ts`. Every fetcher accepts an optional `orgId` and builds the
request against `PUBLIC_API_URL` (default `http://localhost:3002/api`). List
fetchers return an empty array when the API is unreachable; stats fetchers
return `null`. Pages use these return values to decide between live data and the
static fallback.
