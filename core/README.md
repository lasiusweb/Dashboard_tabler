# FirstCrop Core

FirstCrop Core is a set of components and utilities for building web applications. It provides a collection of pre-designed components, such as buttons, forms, modals, and more, that can be easily customized and integrated into your projects.

## 🔎 Preview

FirstCrop is fully responsive and compatible with all modern browsers. Thanks to its modern and user-friendly design you can create a fully functional interface that users will love! Choose the layouts and components you need and customize them to make your design consistent and eye-catching. Every component has been created with attention to detail to make your interface beautiful!

## Installation

To install FirstCrop Core, you can use npm or yarn. Run one of the following commands in your terminal:

```bash
npm install @firstcrop/core
```

or

```bash
pnpm add @firstcrop/core
```
